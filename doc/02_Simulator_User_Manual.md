# AGC Simulation 사용 설명서

이 문서는 **이 프로그램(AGC_Simulation)을 조작하는 방법**을 설명한다. 실제 AGC/DSKY의 원리와 아폴로 우주선의 운용은 `10_AGC_Manual.md`, `11_Apollo_Spacecraft_And_Operations.md`, `12_Mission_Phase_AGC_Guide.md`를 본다.

## 1. 실행

```powershell
dotnet run --project src/Agc.Wpf
```

또는 빌드 후 `src/Agc.Wpf/bin/Debug/net10.0-windows/Agc.Wpf.exe`를 실행한다. 로그는 실행 파일 옆 `logs/agc-yyyyMMdd.log`에 기록된다.

┌─────────────────────────────┬─────────────────────────────────┐

│  - 사령선 CMC / 착륙선 LGC  │  - 단계명 / 설명                │

### 단계 가이드 패널 (오른쪽 아래)

현재 단계에 맞춰 자동으로 바뀐다(단계가 바뀔 때만 다시 그려진다). 위에서부터:

1. **무슨 일이 일어나나** — 이 단계의 미션 설명(실제 MET 포함)
2. **AGC는 무엇을 하나** — 이 단계에서 컴퓨터의 역할
3. **조작 순서 — 무엇을, 왜, 어떤 영향이** — 번호 카드. 각 카드에는 종류(DSKY / 승무원 조작 / 지상 교신 / 관찰), 근거의 확인 수준(확인 / 부분 / 일반 절차 / 미확인), DSKY 키 순서(키패드 글자 그대로), 그리고 **조작 · 목적 · 영향** 설명이 있다.

- **[▶ 실행]** 버튼이 있는 DSKY 단계는 이 시뮬레이터가 지원하는 입력이라 버튼으로 DSKY에 그대로 눌러 볼 수 있다(오른쪽 위 DSKY 화면이 바로 바뀐다). "시뮬레이터 미지원"이라고 적힌 단계는 실제로는 있었던 조작이지만 이 프로그램이 아직 구현하지 않았다.
- "일반 절차" 표시는 실제 키 시퀀스를 공개 자료에서 확인하지 못해 일반적인 방식으로 설명한 것이다.
- 장면과 가이드 사이의 막대를 끌어 높이를 조절할 수 있고, 가이드는 스크롤된다. 내용의 근거는 `12_Mission_Phase_AGC_Guide.md`에 있다.

### 장면

단계에 따라 11가지 장면이 나온다: 발사(새턴 V 상승, 단 분리, 연기·불꽃), 지구 궤도/TLI, 달 전이(지구·달과 궤적), 달 궤도(LOI/LM 분리), 동력 하강(고도계와 지표 접근, 분사 먼지), 달 표면(착륙선, EVA 이후 우주인·성조기), 상승, 랑데부·도킹, 귀환, 대기권 재진입(플라스마), 낙하산 강하와 착수(회수 함정). 지구와 달은 NASA 공개 텍스처를 구에 입혀 태양 방향 음영·대기광·구름까지 계산한다(출처: `ASSETS_CREDITS.md`).

### 미션 뷰 조작

| 조작 | 설명 |
|---|---|
| ▶ 재생 / ⏸ 일시정지 | 미션 시계(MET)를 진행/정지한다. 시작 상태는 정지이다. |
| 배속 | 1×, 10×, 60×, 600×, 3600× (실시간 1초당 흘러가는 미션 시간). 기본 60× |
| 타임라인 슬라이더 | 임의의 MET로 이동(Seek). 건너뛴 구간의 알람은 발생하지 않는다. |
| 단계 이동 | 목록에서 단계를 고르면 그 단계의 시작 시각으로 이동한다. |

미션은 Apollo 11이며 MET 0(발사)부터 195:18:35(착수)까지이다. 수치는 공개 기록에 근거한 근사값이다(자세한 한계는 `00_Development_Plan.md` 4절).

## 3. DSKY 조작 기본

### 3.1 키 입력 방법

- **마우스**로 키패드 버튼을 누르거나 **PC 키보드**를 쓴다.

| DSKY 키 | PC 키 |
|---|---|
| 0–9 | 숫자(상단/넘패드) |
| + / − | `+`(Shift+`=` 또는 넘패드 +) / `-` |
| VERB / NOUN | `V` / `N` |
| ENTR | `Enter` |
| CLR | `C` 또는 `Backspace` |
| PRO | `P` |
| KEY REL | `K` |
| RSET | `R` |

### 3.2 명령 입력 형식

기본 형식은 **VERB 두 자리 → NOUN 두 자리 → ENTR** 이다.

```
V 1 6 N 3 6 ENTR     →  "V16 N36 실행"
```

- VERB/NOUN 키를 누르면 해당 창이 비워지고 새 입력을 받는다. 두 자리가 채워지면 그 필드 입력이 끝난다.
- 잘못 눌렀을 때: 입력 중에 **CLR**을 누르면 입력 중인 창을 지운다. 해당 키를 다시 누르면 처음부터 입력한다.
- 규칙에 어긋난 입력(예: VERB 없이 숫자, 3번째 숫자, 모르는 명령)은 **OPR ERR** 램프가 켜진다. **RSET**으로 끈다.

### 3.3 표시 규칙

- 십진 값은 항상 `+`/`-` 부호가 붙는다. 부호 칸이 비어 있으면 8진 값이다(알람 코드).
- V/N 창이 **깜박이면** 사용자의 입력/응답을 기다리는 중이다(데이터 로드 대기, 프로그램 번호 대기, 프로그램의 깜박임 요청 표시).
- **PROG 창**은 항상 현재 실행 중인 프로그램 번호를 보여 준다(미션 단계에 따라 자동으로 바뀐다).

**프로그램이 스스로 띄우는 표시**: 단계가 시작될 때 프로그램이 표시를 띄운다. 발사(P11)에서는 `V16 N62`(속도·고도변화율·고도), 동력 하강(P63)에서는 `V16 N63`이 나타난다. 앞의 프로그램 표시는 새 프로그램 표시로 바로 교체되지만, 승무원이 직접 명령한 표시는 보호되어 **KEY REL 램프**로 알린다(5.5).

**컴퓨터(DSKY) 전환**: LM 분리(100:12:00)부터 도킹(128:03:00) 전까지는 착륙선 컴퓨터(LGC, Luminary 1A), 그 밖에는 사령선 컴퓨터(CMC, Colossus 2A)로 본다.

## 5. 실습 시나리오

### 5.1 램프 테스트

1. `V` `3` `5` `ENTR`
2. 모든 램프가 켜지고 모든 창에 88이 표시되며 V/N이 깜박인다(시작은 사령선이므로 ALT/VEL 없이 11개). 약 5초 후 램프가 꺼지고 88은 남는다. 테스트 중에 누른 키는 무시된다.
3. `K`(KEY REL)로 표시를 지운다.
4. (착륙선) 단계 이동에서 "동력 하강 시작(PDI)"을 고르고 같은 방법으로 해 보면 ALT/VEL까지 13개가 켜진다.

### 5.2 AGC 시계 보기와 설정

1. `V16 N36 ENTR` — 시/분/초×100을 1초마다 표시
2. 시계 설정: `V25 N36 ENTR` (V/N이 깜박이고 R1~R3이 빈다)
   - R1: `+` `0` `0` `1` `0` `2` `ENTR` (시)
   - R2: `+` `0` `0` `0` `3` `3` `ENTR` (분, 0~59)
   - R3: `+` `0` `0` `5` `0` `0` `ENTR` (초×100, 0~5999)
3. 완료되면 깜박임이 멈추고 입력한 시계 값부터 시간이 흐른다.
- 십진 데이터는 **부호와 5자리를 모두** 입력해야 한다. 틀리면 CLR로 현재 레지스터를 지우고 다시 입력한다.
- N36은 3개 레지스터를 모두 로드해야 하므로 `V25`만 허용된다(`V21 N36`은 OPR ERR).
- 중간에 포기하려면 `V34 ENTR`(종료) 또는 `V33 ENTR`.

### 5.3 달 착륙 하강 감시 (P63)

1. 단계 이동에서 "동력 하강 시작(PDI)"을 고른다(MET 102:33:05). PROG 창이 **63**이 되고, 프로그램이 `V16 N63`을 스스로 띄운다(캡션은 착륙선 컴퓨터).
2. 다른 값을 보고 나서 다시 보려면 `V16 N63 ENTR` — 속도·고도변화율·계산 고도(ft)를 감시한다.
3. 점화 전 카운트다운은 "LM 분리" 단계에서 102:30:00 근처로 이동해 `V16 N62 ENTR`을 누르면 R2에 점화까지 남은 시간(예: `+03 05`)이 줄어든다.
4. ▶재생(60×). 계산 고도가 줄고 고도변화율이 음수가 된다.
4. `V06 N68 ENTR` — 착륙지점까지의 사거리(nm)와 제동 잔여시간을 본다.
5. 102:38:26경 **1202 알람**이 발생해 PROG 램프가 켜진다. `V05 N09 ENTR`로 코드(01202)를 읽고 `R`(RSET)로 램프를 끈다.
6. 102:41:32에 PROG가 **64**, 102:43:20에 **66**, 102:45:40에 **68**(착륙 확인)로 바뀐다.

### 5.4 프로그램 변경 (V37)

1. `V37 ENTR` — V/N이 깜박인다.
2. `0` `0` `ENTR` — P00(대기)으로 바뀐다. 잘못된 번호(예: 99)는 OPR ERR이다.
3. 요청한 프로그램은 **다음 미션 단계로 넘어가면** 그 단계의 프로그램으로 바뀐다(실제로는 승무원이 단계마다 직접 선택).

### 5.5 KEY REL 동작 (프로그램 표시 요청)

프로그램이 단계 시작 때 표시를 요청한다(발사 N62, 동력 하강 N63).

- 승무원이 DSKY를 쓰고 있지 않으면 요청한 Verb/Noun이 바로 표시된다(깜박임 요청이면 V/N 깜박임, `PRO`로 응답). 앞의 프로그램 표시는 그대로 교체된다.
- 승무원이 키를 입력 중이거나 **직접 명령한 표시**가 떠 있으면 KEY REL 램프가 켜지고 요청은 대기한다. `KEY REL` 키를 누르면 승무원의 표시가 지워지고 대기 중이던 요청이 나타난다.
- 해 보기: 처음 화면(P11의 N62)에서 `V06 N36 ENTR`로 직접 표시를 만든 뒤 단계 이동으로 PDI로 가면 KEY REL이 켜지고 N36이 유지된다. `K`를 누르면 N63이 나타난다.

## 6. 현재 미지원 / 한계

- **미지원 Verb/Noun**: 위 표에 없는 것(예: N60, N64, V82, 사령선의 N63/N68(재진입) 등)은 OPR ERR이다. 확장 계획은 `00_Development_Plan.md` 3절.
- 램프 중 UPLINK ACTY, NO ATT, STBY, TEMP, GIMBAL LOCK, RESTART, TRACKER, ALT, VEL은 아직 시나리오에 연결되지 않았다(ALT/VEL은 칸 유무만 우주선에 따라 다르다).
- 점화 전 `V06 N62` 카운트다운 자동 표시, 하강 중 `N64`, 재진입 노운(N60/N61/N63/N64/N67/N68의 사령선 정의)은 아직 없다.
- 프로그램 번호는 미션 타임라인이 정한다. V37 선택은 해당 단계 동안만 유지된다.
- 타임라인 수치는 근사값이며 실제 텔레메트리가 아니다.

## 7. 문제 해결

| 증상 | 확인 |
